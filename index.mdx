Open Recorder is a macOS app for capturing screens, windows, and selected areas, then turning those captures into shareable videos and screenshots.

## What you can do

- Record a display, window, or selected area with microphone, system audio, camera, cursor, and click capture controls.
- Capture screenshots from displays, windows, or selected areas.
- Edit recordings with backgrounds, framing, crop controls, cursor overlays, zooms, timeline edits, and facecam clips.
- Export projects as MOV, MP4, GIF, or PNG files.

## Build from source

Open Recorder requires macOS, Xcode command line tools with Swift 6.2 or later, and Rust 1.93 or later.

```bash
pnpm run setup
make build-macos
make dev-macos
```

See the [Open Recorder repository](https://github.com/imbhargav5/open-recorder) for the full build, packaging, and contribution instructions.
