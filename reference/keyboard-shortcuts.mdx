---
title: "Keyboard shortcuts for screen recording and screenshots"
description: "Global macOS keyboard shortcuts for screenshots and screen recording in Open Recorder, plus the pre-recording HUD and shortcut customization."
---

Open Recorder registers global capture shortcuts that work from any application while the app is running. It also provides standard in-app shortcuts for the editor and project library.

## Global capture shortcuts

These shortcuts trigger captures without switching to the Open Recorder window.

| Shortcut | Action | What it does |
| --- | --- | --- |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>3</kbd> | Device Screenshot | Captures a screenshot of a display. |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>4</kbd> | Drag Screenshot | Lets you select a custom area and captures it as a screenshot. |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>5</kbd> | Device Screen Record | Opens the screen recorder with a display selected and shows the capture HUD in pre-recording mode. |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>6</kbd> | Drag Screen Record | Lets you drag an area to record. Recording starts once you finish drawing the selection, using your current capture settings. |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>R</kbd> | Toggle Recording | Starts the recording that is set up in the HUD, or stops the active recording. |

Pressing <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>5</kbd> or <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>6</kbd> while a recording is in progress stops that recording instead of starting a new capture.

### Pre-recording HUD

The Device Screen Record shortcut no longer starts an instant recording. It opens the capture HUD in pre-recording mode so you can review the setup before capture begins. From the HUD you can:

- Change the capture source (display, window, or area).
- Toggle system audio on or off.
- Toggle the microphone on or off and pick a microphone device.
- Toggle the camera on or off for a facecam track.

Click **Record** in the HUD, or press <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>R</kbd>, to start the recording with the options you selected.

### Customizing global shortcuts

Change any global shortcut in **Settings** under **Global Shortcuts**. Each action offers a set of preset key combinations, and **Restore Default Shortcuts** resets all five actions to the defaults listed above.

## In-app shortcuts

These shortcuts work while an Open Recorder window is focused.

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>N</kbd> | New recording |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>N</kbd> | New screenshot |
| <kbd>⌘</kbd> <kbd>O</kbd> | Open project |
| <kbd>⌘</kbd> <kbd>1</kbd> | Show projects |
| <kbd>⌘</kbd> <kbd>2</kbd> | Show editor |

While a recording is active, the menu bar item also exposes **Stop Recording** with <kbd>⌘</kbd> <kbd>R</kbd>.
