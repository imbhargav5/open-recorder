title: "Keyboard shortcuts for screen recording and screenshots"
description: "Global macOS keyboard shortcuts for screenshots and screen recording in Open Recorder, plus the pre-recording HUD and shortcut customization."
---

Open Recorder registers global capture shortcuts that work from any application while the app is running. It also provides standard in-app shortcuts for the editor and project library.

## Global capture shortcuts

These shortcuts trigger captures without switching to the Open Recorder window.

| Shortcut | Action | What it does |
| --- | --- | --- |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>3</kbd> | Screenshot current display | Captures the display containing the pointer without opening a chooser. |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>4</kbd> | Screenshot selected area | Draw an area and release to capture. |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>5</kbd> | Record current display | Opens setup with the display containing the pointer selected. |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>6</kbd> | Record selected area | Draw an area, review the setup, then press Record. |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>7</kbd> | Screenshot current window | Captures the active app's frontmost capturable window. |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>8</kbd> | Record current window | Opens recording setup for the active app's frontmost capturable window. |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>R</kbd> | Open recorder / Start / Stop | Opens setup when idle, starts a ready recording, cancels a countdown, or stops recording. |

Capture-target shortcuts do not stop an existing recording. Use the start/stop shortcut, the HUD's **Stop** button, or the menu-bar icon to finish it. If the current display or window cannot be resolved, Open Recorder opens the appropriate source chooser.

### After taking a screenshot

Choose **Settings → General → Capture → After taking a screenshot**:

- **Open editor** preserves the editing workflow.
- **Copy to clipboard** copies the raw capture immediately so you can paste it without entering the editor.
- **Save to screenshots folder** saves without opening the editor or changing the clipboard.

Screenshots are saved locally in every mode. A brief HUD message confirms Copy or Save. Choose **Edit Last Screenshot** from the menu bar or HUD context menu to edit the most recent quick capture.

Enable **Adjust selected area before capture** to move the selection, drag its resize handles, and press Return to confirm. Arrow keys move by one pixel; Shift moves by ten. Leave it off to retain quick capture on release.

### Pre-recording HUD

Display, window, and area recording shortcuts open the capture HUD in pre-recording mode so you can review inputs before capture begins. From the HUD you can:

- Change the capture source (display, window, or area).
- Toggle system audio on or off.
- Toggle the microphone on or off and pick a microphone device.
- Toggle the camera on or off for a facecam track.

Click **Record** in the HUD, or press <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>R</kbd>, to start the recording with the options you selected.

Press <kbd>Esc</kbd> during the recording countdown to cancel before capture begins. The HUD returns to its ready state without starting a recording. <kbd>Esc</kbd> also cancels an in-progress area selection.

### Customizing global shortcuts

Change any global shortcut in **Settings** on the **Shortcuts** tab, under **Global Shortcuts**. Open Settings from the menu bar dropdown with **Settings…** or press <kbd>⌘</kbd> <kbd>,</kbd> while an Open Recorder window is focused.

To record a new shortcut:

1. Click the shortcut field next to an action. The field shows **Press shortcut…** and previews modifiers as you hold them.
2. Press the key combination you want. Open Recorder saves it as soon as you release the keys.
3. Press <kbd>Esc</kbd> to cancel recording and keep the current shortcut.

You can record any key combination instead of picking from presets. Open Recorder validates the combination and shows an error under the field if it rejects it:

- The combination must include <kbd>⌘</kbd>, <kbd>⌃</kbd>, or <kbd>⌥</kbd>. Function keys (<kbd>F1</kbd>–<kbd>F20</kbd>) can be used on their own.
- The combination cannot already be assigned to another Open Recorder action.
- The combination cannot match an Open Recorder menu command, such as <kbd>⌘</kbd> <kbd>N</kbd>.
- The combination cannot be reserved by macOS or registered by another application.

Each shortcut shows **Active**, **Off**, or an **Unavailable** warning based on registration. If another app owns a key, quit that app and choose **Retry unavailable shortcuts**, or assign a different combination. Shortcut handling pauses while you record a replacement key. The menu bar and HUD show your configured shortcut hints.

**Restore Default Shortcuts** resets all seven actions to the defaults listed above. Nightly builds keep global shortcuts disabled by default; enable them here when needed.

## In-app shortcuts

These shortcuts work while an Open Recorder window is focused.

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>N</kbd> | New recording |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>N</kbd> | New screenshot |
| <kbd>⌘</kbd> <kbd>O</kbd> | Open project |
| <kbd>⌘</kbd> <kbd>1</kbd> | Show projects |
| <kbd>⌘</kbd> <kbd>2</kbd> | Show editor |
| <kbd>⌘</kbd> <kbd>,</kbd> | Open settings |

The menu bar dropdown also includes a **Settings…** item that opens the Settings window. Settings is organized into three tabs: **General** for recording and folder options, **Shortcuts** for the global capture shortcuts, and **System** for macOS permissions.

While a recording is active, the menu bar item also exposes **Stop Recording** with <kbd>⌘</kbd> <kbd>R</kbd>.

### Screenshot editor

These shortcuts work while the screenshot editor is focused. Each action is also available as a toolbar button in the editor's Export menu.

| Shortcut | Action | What it does |
| --- | --- | --- |
| <kbd>⌘</kbd> <kbd>S</kbd> | Save PNG | Saves the composed PNG next to the source screenshot without changing the clipboard. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>S</kbd> | Save PNG As… | Opens a save panel so you can choose a location and filename for the composed PNG. |
| <kbd>⌘</kbd> <kbd>C</kbd> | Copy PNG | Copies the composed PNG to the clipboard and keeps the editor open. |

These shortcuts are suppressed while you are typing in a text field, so they don't interrupt annotation entry.
